`rpc_call_export_cap` passes a capability this vat hosts in the parameters of an outgoing call, so a client can hand a server a callback object (a subscriber's sink, for example) and receive its calls while it pumps the connection. `rpc_ctx_keep_param_cap` lets a dispatch keep a capability that arrived in its parameters: the reference the call held moves to an import, which the callee releases with `rpc_release_send`.
